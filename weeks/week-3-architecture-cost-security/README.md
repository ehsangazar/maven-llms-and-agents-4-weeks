# Week 3 · Agent architecture, cost & security
**Oct 19 – 25 · S5 Tue Oct 20 · S6 Thu Oct 22 · Project 2 due Wed Oct 21**

The compressed week: the six-week cohort teaches cost/latency and agent
architecture as two separate weeks. Here they are taught together, because you
cannot choose an agent pattern honestly without pricing it, and you cannot cap
spend without knowing which pattern is spending it.
